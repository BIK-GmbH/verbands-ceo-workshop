# <I18n de="Ergebnistypen-Pipeline (technisch)" en="Result-type pipeline (technical)" />

<p>
  <I18n
    de="Für die technisch Interessierten und den Trainer: Wie aus dem Workshop konkrete Ergebnisse entstehen."
    en="For the technically curious and the trainer: how concrete results emerge from the workshop."
  />
</p>

<De>
1. **Erfassen** — interaktive Felder schreiben in den localStorage-Store (kein Server).
2. **Exportieren** — Workshop-Protokoll als Markdown + JSON (Route `/protokoll`).
3. **Regenerieren** — der Repo-Skill `/konzept-neu` liest das Protokoll und erzeugt ein angepasstes Konzept + Folien.
4. **Rendern/Export** — `npm run build` + `npm run export:pdf` erzeugt das PDF aus der Print-Route; alternativ ein Canva-Marken-Deck.
</De>

<En>
1. **Capture** — interactive fields write into the localStorage store (no server).
2. **Export** — workshop record as Markdown + JSON (route `/protokoll`).
3. **Regenerate** — the repo skill `/konzept-neu` reads the record and produces an adapted concept + slides.
4. **Render/export** — `npm run build` + `npm run export:pdf` generates the PDF from the print route; alternatively a Canva brand deck.
</En>

<CommandBox lang="bash">
# Plattform lokal starten
npm run dev
# Konzept-PDF (DE) erzeugen
npm run build
npm run export:pdf
</CommandBox>

<CommandBox lang="bash">
# Aus dem Workshop-Protokoll Konzept + Folien neu generieren
/konzept-neu workshop-protokoll-2026-05-31.md
</CommandBox>
