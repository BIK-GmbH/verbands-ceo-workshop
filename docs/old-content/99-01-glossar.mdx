# <I18n de="Glossar" en="Glossary" />

<De>
| Begriff | Bedeutung |
|---|---|
| **CDBrain** | Corporate/Verbands-Digital-Brain — der durchsuchbare Verbandswissensgraph, das zentrale Gedächtnis des Verbands. |
| **Personal Digital Brain (PDB)** | Rollenbezogener Arbeitsassistent je Person oder Rolle, gespeist aus dem CDBrain. |
| **Composer** | Multimodale Produktionsschicht — erzeugt Dokumente, Folien, Videos und Podcasts aus dem Wissensgraph. |
| **Knowledge Graph** | Semantisches Netz aus Entitäten und Beziehungen statt eines Dokumentenhaufens. |
| **LLM** | Large Language Model — Sprachmodell, hier mit dem Wissensmodell des Verbands verknüpft. |
| **FTE** | Full-Time-Equivalent — Vollzeitäquivalent; ½ FTE = halbe Stelle. |
| **MVP** | Minimum Viable Product — kleinste nutzbare Pilotlösung. |
| **AI Act** | EU-Verordnung, ordnet KI nach Risikoklassen; Transparenzpflichten ab August 2026. |
| **DSGVO** | Datenschutz-Grundverordnung. |
| **RACI** | Verantwortungsmatrix: Responsible, Accountable, Consulted, Informed. |
| **Governance** | Regeln für Zuständigkeiten, Freigaben und Pflege. |
| **Q-Zeichen** | Qualitätszeichen des FBS. |
| **VOB / DIN / VDI** | Technische Regelwerke der Branche. |
</De>

<En>
| Term | Meaning |
|---|---|
| **CDBrain** | Corporate/association digital brain — the searchable association knowledge graph, the central memory of the association. |
| **Personal Digital Brain (PDB)** | Role-based work assistant per person or role, fed from the CDBrain. |
| **Composer** | Multimodal production layer — generates documents, slides, videos and podcasts from the knowledge graph. |
| **Knowledge Graph** | A semantic network of entities and relationships instead of a pile of documents. |
| **LLM** | Large Language Model — language model, here linked to the association's knowledge model. |
| **FTE** | Full-Time Equivalent; ½ FTE = half a position. |
| **MVP** | Minimum Viable Product — smallest usable pilot solution. |
| **AI Act** | EU regulation classifying AI by risk class; transparency obligations from August 2026. |
| **DSGVO** | General Data Protection Regulation (GDPR). |
| **RACI** | Responsibility matrix: Responsible, Accountable, Consulted, Informed. |
| **Governance** | Rules for responsibilities, approvals and maintenance. |
| **Q-Zeichen** | Quality mark of the FBS. |
| **VOB / DIN / VDI** | Technical rulebooks of the industry. |
</En>
