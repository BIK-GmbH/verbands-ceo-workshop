# <I18n de="Glossar" en="Glossary" />

<De>

| Begriff | Bedeutung |
|---|---|
| **KI / LLM (Sprachmodell)** | Künstliche Intelligenz; ein Large Language Model ist ein Sprachmodell, das Texte versteht und erzeugt. |
| **Prompt** | Die Anweisung oder Frage, die man einem Sprachmodell gibt. |
| **Halluzination** | Plausibel klingende, aber falsche Aussage eines Sprachmodells. Deshalb Quellenangaben und menschliche Prüfung. |
| **RAG** | Retrieval-Augmented Generation: Das Sprachmodell sucht vor der Antwort in einer festgelegten Wissensbasis und stützt sich auf die gefundenen Quellen. |
| **Wissensbasis** | Geprüfter, gepflegter Bestand an Dokumenten und Wissen, auf den KI zugreifen darf. |
| **Wissensgraph** | Semantisches Netz aus Begriffen und ihren Beziehungen statt eines Dokumentenhaufens. |
| **KI-Agent** | KI, die Aufgaben in mehreren Schritten selbstständig ausführt, z. B. recherchieren, entwerfen, weiterleiten. |
| **Persönlicher KI-Assistent** | KI-Unterstützung für eine Person oder Rolle, z. B. für Vorbereitung, Entwürfe und Recherche. |
| **Dokumenten-Generator** | Werkzeug, das aus Vorlagen und Wissen Dokumente, Protokolle oder Folien erzeugt. |
| **DSGVO / AVV** | Datenschutz-Grundverordnung; der Auftragsverarbeitungsvertrag (Art. 28 DSGVO) ist nötig, wenn ein Dienstleister personenbezogene Daten im Auftrag verarbeitet. |
| **EU-AI-Act** | EU-Verordnung über künstliche Intelligenz; ordnet KI-Systeme nach Risikoklassen, Pflichten gelten gestaffelt seit 2025. |
| **Governance** | Regeln für Zuständigkeiten, Freigaben und Pflege. |
| **RACI** | Verantwortungsmatrix: verantwortlich (Responsible), entscheidet (Accountable), unterstützt (Consulted), informiert (Informed). |
| **GO / ADAPT / STOP** | Entscheidungsliste aus dem Realitätscheck: weitermachen · anpassen · beenden. |
| **5× Warum** | Methode, bei der man so lange nach dem Warum fragt, bis die eigentliche Ursache statt des Symptoms sichtbar wird. |
| **MVP** | Minimum Viable Product: kleinste nutzbare Lösung zum Ausprobieren. |
| **FTE** | Full-Time-Equivalent: Vollzeitäquivalent, Maß für Personalkapazität. |
| **Q-Zeichen** | Qualitätszeichen des FBS. |
| **VOB / DIN / VDI** | Technische Regelwerke der Branche. |

</De>

<En>

| Term | Meaning |
|---|---|
| **AI / LLM (language model)** | Artificial intelligence; a large language model is a language model that understands and generates text. |
| **Prompt** | The instruction or question you give a language model. |
| **Hallucination** | A plausible-sounding but false statement by a language model. Hence source references and human review. |
| **RAG** | Retrieval-augmented generation: before answering, the language model searches a defined knowledge base and relies on the sources it finds. |
| **Knowledge base** | A verified, maintained collection of documents and knowledge that AI is allowed to access. |
| **Knowledge graph** | A semantic network of terms and their relationships instead of a pile of documents. |
| **AI agent** | AI that carries out tasks in several steps on its own, e.g. researching, drafting, forwarding. |
| **Personal AI assistant** | AI support for one person or role, e.g. for preparation, drafts and research. |
| **Document generator** | A tool that creates documents, minutes or slides from templates and knowledge. |
| **GDPR (DSGVO) / DPA (AVV)** | General Data Protection Regulation; the data processing agreement (Art. 28 GDPR) is required when a service provider processes personal data on your behalf. |
| **EU AI Act** | EU regulation on artificial intelligence; classifies AI systems by risk class, obligations apply in stages since 2025. |
| **Governance** | Rules for responsibilities, approvals and maintenance. |
| **RACI** | Responsibility matrix: Responsible, Accountable, Consulted, Informed. |
| **GO / ADAPT / STOP** | Decision list from the reality check: continue · adapt · stop. |
| **5 whys** | A method of asking why until the actual cause rather than the symptom becomes visible. |
| **MVP** | Minimum viable product: the smallest usable solution to try out. |
| **FTE** | Full-time equivalent, a measure of staff capacity. |
| **Q-Zeichen** | Quality mark of the FBS. |
| **VOB / DIN / VDI** | Technical rulebooks of the industry. |

</En>
